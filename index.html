What it does
and why it matters.

BirdWatcher uses AI to analyse videos, locate birds, and identify their species. You can upload hours of footage from a garden camera, or short videos taken on your mobile phone. The software will generate a folder named after each bird that is identified in the video and in these folders will be images of the birds and the timestamp at which they appear. This is a great way to track what is visiting your feeders throughout the day or to identify birds which you don't know.

First launch

Install BirdWatcher.

macOS

  1. Double-click the downloaded .dmg file.
  2. Drag BirdWatcher into the Applications folder.
  3. Open BirdWatcher from Applications.
  4. If macOS says it cannot open the app, go to System Settings > Privacy & Security and choose Open Anyway. You only need to do this the first time.

Windows

  1. Run the downloaded .exe installer.
  2. When the security pop-up appears, click More info.
  3. Click Open anyway to start the installation.

Linux

  1. Extract the downloaded .tar.gz archive.
  2. Open the extracted folder in a terminal.
  3. Make the app executable with chmod +x BirdWatcher.
  4. Start it with ./BirdWatcher.
